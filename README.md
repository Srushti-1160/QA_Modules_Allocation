UAT Module Allocation Dashboard is a web page that shows which ANTZ modules each QA tester is responsible for and how far testing has got. Each module lists its masters, reports, features and notifications as a tree, with separate App and Web statuses. The top of the page shows total, completed and pending modules for the selected build. It follows the release flow: SaaS (UAT, then Production on TestFlight or App Store) and Vantara (Staging, then live), with a fresh status list for every new build. Testers can also add notes, drag modules between people, and import new feature lists from Excel or Word.
